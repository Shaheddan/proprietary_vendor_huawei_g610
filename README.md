# Proprietary vendor files for the Huawei Ascend G610-U20 (CyanogenMod 10.1)

Blobs extracted from the stock Huawei Android 4.2.1 firmware (MT6589), used by
[android_device_huawei_g610](https://github.com/Shaheddan/android_device_huawei_g610)
(branch `cm-10.1`). Clone to `vendor/huawei/g610`.

These files are proprietary to Huawei and MediaTek and are provided only to build
the ROM for this device.
